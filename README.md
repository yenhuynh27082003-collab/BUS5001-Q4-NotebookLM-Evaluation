# BUS5001-Q4-NotebookLM-Evaluation

This repository contains the prompts and outputs generated during the evaluation of Google NotebookLM for BUS5001 Assessment 3.

The evaluation used two uploaded sources:

- BUS5001 Assessment 3 brief
- BUS5001 Assessment 3 rubric

## Experiments

### Experiment 1: Source-grounded chat

This file contains the prompt used to ask NotebookLM to identify the main assessment requirements, learning outcomes and expectations, together with the generated output.

### Experiment 2: Study guide

This file contains the prompt used to generate a structured study guide, together with the NotebookLM output.

### Experiment 3: Comparison and synthesis

This file contains the prompt used to compare the assessment requirements, required evidence and High Distinction expectations, together with the generated output.

### Experiment 4: Mind map

This file contains the prompt used to generate a visual mind map of Q1, Q2, Q3 and Q4, together with the generated output.

The visual result is provided as:

- `Screenshot_75.png`

## Purpose

The repository provides supporting evidence for the Q4 evaluation of NotebookLM. It records the prompts, generated outputs and visual evidence used in the report.
